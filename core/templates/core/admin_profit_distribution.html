Distribution Rule

Total profit is split by active investment ratio first. Then each investor's gross share is divided into own profit and referral commission by the configured L1-L6 rates.

  • L6 = investor own profit
  • L1 = nearest referrer
  • L5 = farthest eligible upline
  • Missing L1-L5 levels go to the unsettled account
  • If L6 is not configured, the system uses 100 - (L1+L2+L3+L4+L5) as own profit
